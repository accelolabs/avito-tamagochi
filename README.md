# Авито Тамагочи

MVP виртуального питомца, который развивается от полезных действий пользователя на классифайде и открывает персональные бонусы Авито.

## Пользовательский сценарий

1. Пользователь регистрируется и автоматически получает питомца Киту (`K1-T4`).
2. Пользователь заряжает Киту и выполняет ежедневные задания, связанные с активностью на Авито.
3. Действия изменяют состояние питомца и начисляют опыт.
4. Опыт повышает уровень, развивает питомца и открывает персональные награды.
5. Лидерборд, ежедневная сводка и обновления в реальном времени показывают прогресс и мотивируют вернуться.

## Решения MVP

- Кита развивается через стадии яйца, ребёнка, подростка и взрослого питомца.
- Батарея лениво уменьшается при первом обращении после `00:00 МСК`; отдельный scheduler не используется.
- Три фиксированных ежедневных задания связаны с просмотром, добавлением в избранное и публикацией объявлений.
- Награды — два бессрочных непередаваемых бонуса аккаунта на продвижение объявлений и Авито Доставку.
- Лидерборд строится по суммарному XP.
- Ежедневная сводка показывает XP, зарядки, выполненные задания и открытые награды текущих суток.
- HTTP-запросы сразу возвращают результат пользовательской команды.
- WebSocket отправляет одно событие `game.updated` с полным игровым состоянием после события основной платформы.

## Стек

- Frontend: React 19, TypeScript, Vite, ESLint, Nginx.
- Backend: Go 1.25, Gin.
- Data: PostgreSQL 18.
- Infrastructure: Docker Compose.

Проект реализуется как модульный монолит. PostgreSQL является единым источником истины, а Nginx предоставляет общий origin для SPA, HTTP API и WebSocket.

## Запуск

Требуется Docker с Docker Compose.

```bash
cp .env.example .env
docker compose up --build

# Для запуска с демонстрационными пользователями лидерборда
docker compose --profile demo up --build
```

Приложение будет доступно по адресу <http://localhost:3000>.

```bash
docker compose ps
docker compose down
```

PostgreSQL доступен только внутри Docker-сети и не публикует порт на хост. Схема автоматически применяется одноразовым сервисом `migrate` до запуска backend. Demo-данные включаются только профилем `demo`; повторный запуск безопасен.

Для удаления demo-данных:

```bash
docker compose run --rm seed cleanup
```

Для backup без открытого PostgreSQL-порта:

```bash
mkdir -p backups
docker compose exec -T postgres pg_dump -U tamagotchi -d tamagotchi > backups/tamagotchi.sql
```

Для восстановления:

```bash
docker compose exec -T postgres psql -U tamagotchi -d tamagotchi < backups/tamagotchi.sql
```

## API

HTTP API использует префикс `/api/v1`. WebSocket доступен отдельно по `/ws`.

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/api/v1/auth/register` | Регистрация, создание питомца и сессии |
| `POST` | `/api/v1/auth/login` | Вход |
| `POST` | `/api/v1/auth/logout` | Завершение сессии |
| `GET` | `/api/v1/pet` | Текущее состояние питомца |
| `POST` | `/api/v1/pet/actions` | Действие по уходу за питомцем |
| `GET` | `/api/v1/tasks` | Ежедневные задания |
| `POST` | `/api/v1/demo/activities` | Имитация активности пользователя на Авито |
| `GET` | `/api/v1/rewards` | Персональные награды и прогресс к ним |
| `POST` | `/api/v1/rewards/{rewardId}/claim` | Получение открытой награды |
| `GET` | `/api/v1/leaderboard` | Лидерборд по суммарному XP |
| `GET` | `/api/v1/summary/daily` | Сводка за текущие сутки |
| `GET` | `/ws` | Подключение к серверным обновлениям |

Точные схемы запросов, ответов, ошибок и WebSocket-событий описаны в [OpenAPI-контракте](api/openapi.yaml).

## Текущее состояние

Уже реализовано:

- монорепозиторий с frontend и backend;
- Docker Compose для React/Nginx, Go и PostgreSQL;
- проксирование `/api` и `/ws` через Nginx;
- каркас backend на Go и Gin;
- черновая реализация регистрации пользователя и создания питомца.

Предстоит реализовать:

- завершение авторизации и middleware сессий;
- игровую прогрессию, задания и безопасную выдачу наград;
- WebSocket-события, лидерборд и ежедневную сводку;
- unit-тесты бизнес-логики и конфигурацию Go-линтера;
- публичный стенд.
