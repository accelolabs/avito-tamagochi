# Тестирование игры

## Основные сценарии

- Новый пользователь получает питомца с зарядом 50%, 0 XP и уровнем 1.
- Заряд достигает 0 через 48 часов, а зарядка восстанавливает его до 100%.
- Зарядка начисляет 10 XP не чаще одного раза за московский день.
- Задания следуют фиксированной трёхдневной ротации; незавершённый прогресс не переносится.
- Пять действий `view` закрывают задание просмотра, остальные действия закрывают одно задание сразу.
- Повторное выполнение завершённого задания не начисляет XP.
- Каждые 100 XP повышают уровень и открывают соответствующую персональную награду.
- Награда принадлежит одному пользователю и используется только один раз.
- Сводка использует только текущий день в `Europe/Moscow`.
- Лидерборд возвращает top-10 и позицию текущего пользователя.

## Границы и транзакции

- Запросы непосредственно до и после `00:00 MSK`.
- Заряд в момент создания, ровно через 48 часов и после 48 часов.
- Параллельное создание питомца и параллельная зарядка.
- Параллельное выполнение последнего шага задания.
- Повторное использование награды.
- Ошибка транзакции не оставляет частичный XP, прогресс или награду.
- WebSocket-событие отправляется только после успешного commit и не содержит игровых данных.

## Обязательные проверки

```bash
cd backend && go test ./...
cd frontend && npm run lint && npm run build
```

Публичный API должен быть описан в `api/openapi.yaml` и `docs/game-api.md`.

## Live-проверка backend без frontend

Для проверки REST и WebSocket backend можно использовать изолированный Compose-проект:

```bash
scripts/live_backend.sh --all
```

Скрипт поднимает только `postgres`, `migrate` и `backend`, использует отдельный volume `avito-tamagotchi_live_data`, регистрирует тестовых пользователей и проверяет auth, питомца, mock Avito actions, задания, XP, уровни, награды, summary, leaderboard, конкурентную зарядку и WebSocket-события.

Frontend не запускается. Для остановки stack и удаления только live-volume:

```bash
scripts/live_backend.sh --no-start --all --stop
```

Скрипт требует `docker`, `curl`, `python3` и использует встроенный Go WebSocket listener из `backend/cmd/live-ws-listener`.
