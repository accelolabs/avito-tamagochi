# GDD: Авито Тамагочи

## 1. Цель

Авито Тамагочи формирует привычку возвращаться в приложение и связывает игровую активность с действиями на Авито.

Пользователь получает питомца, заботится о нём, выполняет задания на мок-платформе Авито, получает XP, открывает персональные награды и сравнивает прогресс с другими пользователями.

## 2. Питомец

Питомец создаётся автоматически при первом обращении пользователя к игровому API.

Начальное состояние:

- заряд — 50%;
- XP — 0;
- уровень — 1.
- стадия — `egg`.

Заряд полностью расходуется линейно за 48 часов. Зарядка сразу восстанавливает его до 100%.

Зарядка — единственное действие с питомцем. Пользователь отправляет строку `"charge"`. Она даёт 10 XP только один раз за московский календарный день.

Frontend плавно уменьшает заряд локально. Backend остаётся источником истины и пересчитывает заряд при каждом REST-запросе.

## 3. Прогрессия

Уровень считается линейно:

```text
level = floor(xp / 100) + 1
```

Стадия питомца вычисляется напрямую из уровня и не хранится отдельно:

| Уровни | Стадия API |
| --- | --- |
| 1–2 | `egg` |
| 3–5 | `child` |
| 6–8 | `teen` |
| 9 и выше | `adult` |

На уровнях 3, 6 и 9 питомец переходит на следующую стадию. Значение стадии возвращается backend на английском языке.

Каждые 100 XP открывают новый уровень. При достижении нескольких уровней сразу открываются все пропущенные награды.

## 4. Задания

Пользователь получает три задания на московский день. Используется фиксированный трёхдневный цикл:

| День цикла | Задания |
| --- | --- |
| 1 | посмотреть 5 объявлений, добавить объявление в избранное, разместить объявление |
| 2 | посмотреть 5 объявлений, разместить объявление, разместить объявление в категории |
| 3 | добавить объявление в избранное, разместить объявление, разместить объявление в категории |

После третьего дня цикл повторяется. Незавершённые задания на новый день не переносятся.

XP за задания:

- посмотреть 5 объявлений — 20 XP;
- добавить объявление в избранное — 25 XP;
- разместить объявление — 40 XP;
- разместить объявление в категории — 50 XP.

Просмотр закрывается после пяти действий `view`. Остальные задания закрываются одним действием. Повторное действие после выполнения не даёт XP.

## 5. Награды

Награда — персональное право воспользоваться бонусом, а не промокод.

Награды открываются начиная с уровня 2 и чередуются:

| Уровень | Награда |
| --- | --- |
| 2 | продвижение объявления |
| 3 | бесплатная доставка |
| 4 | продвижение объявления |
| 5 | бесплатная доставка |

Каждая открытая награда принадлежит конкретному пользователю и может быть использована один раз.

Использование любой награды демонстрируется через общий mock-эндпойнт. Для использования не нужны дополнительные параметры.

## 6. Ежедневная сводка

Московский день длится с `00:00` до `00:00` следующего дня в timezone `Europe/Moscow`.

Сводка за текущий день показывает:

- заработанный XP;
- выполненные задания;
- количество зарядок;
- достигнутый уровень;
- открытые награды;
- текущий заряд, уровень и общий XP.

Если активности не было, пользователь получает нулевую сводку.

## 7. Лидерборд

Лидерборд сортируется по общему XP:

```text
XP DESC, user_id ASC
```

Показываются top-10 пользователей и отдельное место текущего пользователя, если он не попал в top-10.

## 8. MVP-ограничения

- PostgreSQL — источник истины.
- Все изменения выполняются синхронно и транзакционно.
- WebSocket отправляет только короткое имя события; данные frontend получает через REST.
- Фоновые задачи, cron, Redis, очереди и message broker не используются.
- Награды не являются реальными промокодами: их использование демонстрируется mock-операцией.
