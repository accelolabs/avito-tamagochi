# Архитектура

Пользователь обращается к приложению через Nginx на порту `3000`. Nginx отдаёт собранное React SPA, перенаправляет запросы `/api/*` в Go-backend на порт `8080`, а соединения `/ws` - в его WebSocket endpoint. Backend выполняет бизнес-логику и работает с PostgreSQL. Напрямую извне доступны только Nginx и опубликованное через него приложение.

## Решения

- Go modular monolith: минимум операционной сложности для хакатона.
- PostgreSQL: транзакции, ограничения, блокировки и запросы лидерборда.
- Nginx: один origin для UI, cookie-авторизации, API и WebSocket.
- Docker Compose: воспроизводимый локальный запуск и деплой.
- Backend и PostgreSQL не публикуются наружу.

## Планируемые backend-модули

- `auth` - пользователи и серверные сессии.
- `pet` - состояние питомца.
- `progression` - действия, XP и уровни.
- `rewards` - персональная одноразовая выдача.
- `realtime` - WebSocket.
- `leaderboard`, `summary` - рейтинг и ежедневная сводка.

## Инварианты

- Клиент не задаёт XP, уровень и право на награду.
- Изменение питомца и запись события выполняются атомарно.
- Награда принадлежит одному пользователю и не используется повторно.
- WebSocket-события отправляются после успешного сохранения.

Сейчас реализованы инфраструктурный каркас и `/api/health`; бизнес-модули ещё не добавлены.
