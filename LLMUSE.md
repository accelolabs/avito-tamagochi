# Использование LLM в проекте

В этом проекте мы используем LLM для ускорения разработки и реализации бизнес-логики.

## Реализованные задачи

- **Реализация эндпоинтов `register`, `login`, `logout`:**
  - Написан код для домена `auth` в соответствии с `openapi.yaml`.
  - Реализовано хэширование паролей с использованием Argon2id.
  - Добавлена нормализация email.
  - Настроено управление сессиями через HttpOnly cookies.
  - Обеспечена транзакционность при регистрации пользователя и создании питомца.
  - Реализована обработка ошибок в соответствии со спецификацией.
  - Обновлена схема базы данных и основное приложение.
- **Рефакторинг и исправление ошибок:**
  - Устранение проблем со сборкой Docker.
  - Исправление ошибок подключения к базе данных.
  - Рефакторинг структуры проекта для соответствия Clean Architecture.
  - Переход с `net/http` на `gin`.
